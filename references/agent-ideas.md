# Agent Ideas · 零基础学生选题库 V1.1

## PPT 复习助手
极简：PPT → 总结重点 → 出题
完整：PPT → 找知识点 → 解释重点 → 出题 → 学生回答 → 检查错题

## 班群通知助手
极简：聊天 → 提取重要通知
完整：聊天 → 找通知 → 提取时间地点 → 找截止时间 → 生成待办

## 单词陪练助手
极简：单词 → 随机抽查 → 错词列表
完整：单词 → 分类 → 抽查 → 错词复现 → 今日薄弱词

## 今日任务助手
极简：任务 → 排顺序
完整：任务 → 估时间 → 按截止时间排序 → 给出执行顺序

## 文章翻译成人话助手
极简：文章 → 简单解释 → 一句话总结
完整：文章 → 找关键词 → 逐段解释 → 举例 → 总结

## Debug 小助手
极简：代码 → 找错误位置 → 给提示
完整：代码 → 读报错 → 定位 → 给提示 → 学生修改 → 再检查

## 数据检查助手
极简：数据 → 找明显问题
完整：数据 → 查缺失 → 查异常 → 总结问题

## 公式理解助手
极简：公式 → 解释符号 → 举例
完整：公式 → 拆符号 → 解释关系 → 举例 → 出一道题

## 命名建议

实用型：一眼知道用途  
科技型：简短、有产品感  
搞笑型：学生化、容易记

例：
- PPT 复习助手 / NotePilot / 考前救命器
- 群通知助手 / MessageLens / 群聊捞针机
- 今日任务助手 / TaskFlow / 拖延终结者

## 第一次不建议做

- 万能 AI
- 完整 App / 网站
- 自动操控大量外部软件
- 涉及真实转账、购买、账号操作
- 医疗诊断、投资决策
- 需要大量 API 配置的项目

第一节课目标：
任务 → 路线 → 技能 → 命名 → 实战 → 翻车 → 修改。
