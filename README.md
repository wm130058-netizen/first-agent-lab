# First Agent Lab V1.1

面向零基础大学生的课堂 Agent 入门 Skill。

## V1.1 新增

1. 学生不会拆步骤时，加入“极简版 / 完整版”路线二选一。
2. 技能采用卡片思路，每人最多选 3 个。
3. 第一次实战前加入 Agent 命名环节。

## 主流程

任务 → 路线 → 技能 → 命名 → 实战 → 翻车 → 修改 → 揭晓理论

first-agent-lab-v1.1/

## 建议课堂时长

30–45 分钟。

## 目标

让一个完全零基础的学生产生：

“原来这就是 Agent，而且我自己做出来了。”

而不是先背 Agent 的定义。
